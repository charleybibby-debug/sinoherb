# 体质自由聊天输入设计

## 目标

删除体质对话中的全部预设选项，让用户通过输入框自由描述身体感受。三轮对话完成后，右侧一次性生成体质检测结果。

## 交互

- 对话区底部使用多行输入框和发送按钮，不显示任何预设回答。
- `Enter` 发送，`Shift + Enter` 换行。
- 前两轮从用户描述中匹配九种体质的常见信号并累积分数。
- 第三轮识别饮食、泡脚或体验偏好；用户也可以表达“没有偏好”。
- 如果当前回答没有可识别信息，保留当前轮次并请用户补充，不生成错误结果。
- 三轮完成后禁用输入框，右侧一次性显示结果；重新开始后恢复输入。

## 范围

只修改体质对话的 HTML、CSS 和本地 JavaScript 规则，不接入外部模型或服务。
