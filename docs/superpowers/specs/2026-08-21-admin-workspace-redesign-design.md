# SinoHerb 桌面运营后台重设计

## 目标

把当前单页堆叠式后台改成宽屏桌面运营工作台，保留现有登录、订单、产品上下架、图片上传和模型状态能力，不增加移动端布局。

## 视觉方向

延续 SinoHerb 的米白背景、深墨绿导航、低饱和金色强调和现有字体体系。减少大圆角卡片和装饰性阴影，优先使用固定侧栏、表格、分组列表和明确的操作按钮，提升信息扫描速度。

## 页面结构

- 左侧固定导航：品牌标识、概览、订单、产品与库存、全站图片、模型状态
- 顶部工具栏：当前页面标题、服务状态、管理员用户名、退出
- 概览：真实数据摘要（已上架产品、已下架产品、待联系订单、图片位数量）和最近订单/需要处理的产品
- 产品与库存：状态筛选、产品表格、库存、状态、更新时间、上架/下架按钮
- 全站图片：页面分组、较大预览、图片位名称、替代文本、替换与恢复操作
- 模型状态：提供商、模型名、当前是否使用本地降级规则

## 交互

侧栏导航只切换桌面工作台内的内容面板，不刷新页面。产品状态筛选和图片分组保持选中状态；所有操作显示成功或失败反馈。退出回到登录面板。

## 响应式范围

本次只支持桌面宽屏（建议 1100px 以上），不为手机和平板添加专门布局；小于桌面宽度时保持可读的最小宽度和横向滚动。
