# 体质对话双栏布局设计

## 目标

将“我的体质”页面的检测容器明确为左右双栏：左侧承载聊天问答，右侧承载体质检测结果。用户完成三步对话后，右侧一次性更新为结果；检测前保持清晰的等待状态。

## 设计

- 使用一个统一的 `chat-layout` 网格容器，桌面端左侧聊天、右侧结果，两个面板等高对齐。
- 左侧 `chat-card` 保留对话记录、三步进度、选项回复、重新开始和产品入口。
- 右侧 `result-card--chat` 作为结果面板，检测前展示等待提示，完成后展示体质名称、核心解释、调养建议、产品类型和产品入口。
- 右侧结果不随单个回答变化；三步完成后由现有本地规则一次性生成。
- 小屏幕下双栏改为上下布局，聊天在上、结果在下，所有现有按钮和对话交互保持不变。

## 视觉规则

- 左右面板使用相同圆角、边框和阴影语言，右侧用柔和的浅绿色背景区别结果状态。
- 桌面端使用约 58% / 42% 的列比例和 18px 间距。
- 结果生成后增加 `is-ready` 状态，使用轻微高亮而非强烈动画，避免干扰阅读。

## 范围

只修改 `my-constitution.html`、`styles.css` 和 `script.js` 中体质对话相关代码；不改变产品数据、购物车或其他页面。
